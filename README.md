# ИС «ПроектОрг»: работающий макет АИС

Практическое занятие № 5 «Разработка прототипа АИС», задание 2: макеты экранных форм с элементами защиты.
Вариант 3: информационная система проектной организации (ТЗ из ПЗ № 2, требования ТБ-1…ТБ-14 из ПЗ № 4.1, V-модель ЖЦ из ПЗ № 4).

Макет работает в браузере без сервера. Данные хранятся в `localStorage`, сеанс — в `sessionStorage`. Все данные вымышленные.

## Экранные формы (задание 2)

1. **Вход в систему** — пароль скрыт, после 5 неуспешных попыток блокировка на 15 мин с обратным отсчётом.
2. **Главное окно** — меню строится по роли (варианты меню для пользователя и администратора показаны в разделе «О прототипе»).
3. **Список объектов** — договоры, проекты, сотрудники, оборудование: поиск, фильтры, сортировка.
4. **Карточка объекта** — карточка сотрудника с маскированием ПДн (паспорт `**** **1234`, СНИЛС, телефон, e-mail).
5. **Отчёт / печатная форма** — гриф «Коммерческая тайна» / «Конфиденциально», водяной знак с логином и временем.
6. **Журнал событий** — доступен только администратору безопасности.

Кроме того: подтверждение опасных действий, проверка ввода в формах, тайм-аут сеанса (10 мин, предупреждение за 60 с),
схема навигации и чек-лист безопасности — в разделе **«О прототипе»** (`#/about`).

## Публикация на GitHub Pages

1. Создайте на GitHub публичный репозиторий, например `proektorg-ais`.
2. Загрузите в корень репозитория содержимое этой папки: `index.html`, `.nojekyll`, `README.md` и папку `assets/`
   (через **Add file → Upload files** или `git push`).
3. Откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Source: Deploy from a branch**,
   ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/proektorg-ais/`.

Локально макет открывается двойным щелчком по `index.html`.

## Структура

```
index.html        — точка входа
assets/style.css  — оформление (светлая и тёмная темы, адаптив, печать)
assets/data.js    — синтетические начальные данные
assets/app.js     — логика: аутентификация, роли, маскирование, журнал, формы, отчёты
```
